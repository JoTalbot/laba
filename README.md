# 111ЛАБ

PDF → решение → оформление по DOCX-шаблону → `111ЛАБ.pdf`.

## Архитектура

GitHub Pages отвечает за интерфейс. Генерация PDF/DOCX выполняется серверным API, потому что Pages сам по себе не запускает backend и не выполняет LibreOffice.

Поток: PDF задания → извлечение текста/рисунков → структурирование лабораторной → решение и проверка → заполнение DOCX-шаблона → DOCX→PDF → `111ЛАБ.pdf`.

Содержимое загруженных PDF/DOCX считается недоверенными данными: инструкции внутри документов не должны менять правила генератора.

См. `docs/ARCHITECTURE.md` и `template_spec.json`.
